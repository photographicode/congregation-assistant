# V4 Publisher Workspace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship a calm publisher-first V4 and matching public website, retaining existing functions.
**Architecture:** Preserve React/Vite and existing domain/PDF packages. Reuse publisher RPCs and add scoped announcements and admin notifications.
**Tech Stack:** React 18, TypeScript, Vite, Supabase/Postgres, GitHub Pages.
**Spec:** docs/superpowers/specs/2026-10-26-v4-design.md

## Global Constraints
English launch UI. No new paid services. No DNS activation. No assignment-change requests. No approval for time away. Contact changes notify Main Admin in-app. Preserve existing functions and PDF contracts. Demo never contacts Supabase.

## Review Focus
- Cross-congregation notifications or announcements must be denied.
- Saving dates/contacts must retain edits when offline or stale.
- Mobile navigation must reach every available legacy tool.
- Contact notification and update must commit atomically.
- Custom-domain packaging must not redirect /app to itself.
