# Reporting a vulnerability

Please use the Support contact in the application Help section or on the public website. The current public address is configured in `support-config.js`; generated bundles use the same configuration.

Describe the affected feature, steps to reproduce with fictional records, browser/version, and the expected result. Do not send passwords, private keys, real publisher information or private links. Do not test against other congregations or alter their records. Please report privately before publishing exploit details.

Reports are reviewed by the service operator. No guaranteed response or resolution time is promised. This is not a bug-bounty programme. Production records are not currently end-to-end encrypted.
