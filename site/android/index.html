The free progressive web app is the recommended way to install.

Android

  1. Open the application in Chrome or Samsung Internet.
  2. Choose the browser menu, then Install app or Add to Home screen.
  3. Confirm, then open Congregation Assistant from your Home Screen.

Firefox menu wording varies by version. If installation is unavailable, bookmark the app and use the browser.

iPhone & iPad

  1. Open the app in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Open the installed app before enabling supported notifications.

Web push requires an installed web app on supported iOS versions (16.4 or later). Sender configuration is also required; installation alone does not prove background delivery.

Desktop

Open the application in Chrome or Edge. Use the install icon in the address bar or the browser’s app menu.

Optional Android APK

A signed APK is not available yet. The owner must configure Android signing keys and Digital Asset Links. No download is advertised until a verified release exists.

When a signed APK is published: download it from the verified release, allow Install unknown apps for that browser temporarily, install it, and turn that permission off afterwards.
